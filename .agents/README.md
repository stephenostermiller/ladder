# Instructions for AI Agents

## Build Process

After making code changes, **always run `make`** to build and test:

```bash
make
```

The `make` command will:
- Run all tests
- Regenerate the site for testing
- Handle all necessary build steps

**Important:** Do not run `make clean`. Make has proper dependency detection and will automatically rebuild only what's necessary when files change.

Do not use individual build commands like `npm run build` or `npm test` directly.

## Project Overview

- `js/` - JavaScript source code and tests
- `java/` - Java source code and tests
- `site/` - Website files (HTML templates, styles)
- `levels/` - Game level files
- `build/` - Build output directory (generated by `make`)
