Ladder brings us back to the days of classic computer games. Yes, there were computer games before there were fancy graphics.

Using only ASCII characters, ladder was an addictive game that was very popular for computers running the CPM operating system. Seeing the game, you might be very much reminded of "Donkey Kong". Now Ladder has been rewritten in Java and can be played on most of todays computers.

Features:

With the new Ladder, written in Java you can:
  • Play all the levels of the original game!
  • Play new levels included in the game!
  • Make your own levels!
  • Jump der rocks all day!

Running the game:

Ladder is written in Java. You will need a java runtime environment. Ladder is written in Java 2 so you will need a runtime environment of Java 1.2.1 or later.

Once java is installed, just double click on the jar file to start Ladder!

Or, add the jar file to your classpath and run java com.Ostermiller.Ladder.Ladder

Known bugs:

  • Bonus time is not done correctly. You get 2000 for each level.

Instructions:

You are a lad trapped in a maze. You're mission is to explore the dark corridors never before seen by human eyes and find hidden treasures and riches.

You control the lad by typing the direction buttons and by jumping by typing SPACE. But beware of the falling rocks called Der rocks. You must also find and grasp the treasure (shown as $) BEFORE the bonus time runs out.

A new lad will be awarded for every 10,000 points. Extra points are awarded for touching the gold statues (shown as &). You will receive the bonus time points that are left when you have finished the level.

Remember, there is more than one way to skin a cat. (Chum)

Good luck lad.
